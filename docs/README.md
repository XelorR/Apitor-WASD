# Печатные инструкции для детей (`docs/`)

Здесь живёт «Большая инструкция для юных пилотов» — книжка для детей
6–15 лет: как подключить робота, как ехать, первые программы, испытания,
словарик и шпаргалка. Версии две — русская и английская — и они
собираются из одного набора исходников.

| Файл | Что это |
|---|---|
| `instructions-ru.md`, `instructions-en.md` | текст инструкций (markdown) |
| `diagrams/*.dot` | схемы на языке Graphviz — правятся текстом |
| `img/*.svg` | готовые схемы (их делает `build.sh`) |
| `style.css` | оформление: шрифты, врезки, обложка, разрывы страниц |
| `pageref.py` | подставляет номера страниц в ссылки `{{page:N}}` |
| `build.sh` | сборка: схемы → HTML → PDF |
| `instructions-ru.pdf`, `instructions-en.pdf` | готовые PDF для печати (A4) |

Схемы в `img/` и готовые PDF лежат в git: книжку можно печатать сразу,
ничего не собирая, а markdown-файлы — читать прямо на GitHub (он рисует
SVG из `img/`). HTML — промежуточный файл, он в git не хранится.

## Как собрать

Нужны четыре программы: `pandoc`, `graphviz` (команда `dot`), `calibre`
(команда `ebook-convert`) и `pdftotext` из poppler — им `pageref.py`
читает готовый PDF, чтобы узнать номера страниц. На Debian/Ubuntu:

```bash
sudo apt install pandoc graphviz calibre poppler-utils
```

Потом:

```bash
docs/build.sh          # собрать оба языка
docs/build.sh ru       # только русский
docs/build.sh en       # только английский
```

Скрипт пересоберёт все схемы в `img/`, сделает HTML и напечатает PDF:
A4, шрифты Noto Sans, номера страниц внизу (`Пульт Apitor · стр. N`).

## Как править

* **Текст** — обычный markdown в `instructions-ru.md` и
  `instructions-en.md`. Главы — заголовки `#`, подглавки — `##`.
  Врезки: `<div class="tip">подсказка</div>`, `.warn` — «осторожно»,
  `.mission` — «испытание».
* **Схемы** — файлы `diagrams/*.dot`; после правки запустите
  `docs/build.sh` (или только `dot -Tsvg diagrams/имя.dot -o img/имя.svg`).
  Подписи можно писать по-русски: для схем берётся шрифт Noto Sans.
* **Оформление** — `style.css`: цвета заголовков, рамки врезок,
  обложка и разрывы страниц.

## Как получаются страницы

Разрывы страниц в PDF задаёт `--page-breaks-before="//*[name()='h1']"`
(см. `build.sh`): каждая глава `#` начинается с новой страницы, подглавки
`##` идут внутри главы. Обложка — обычный HTML-блок `.cover`, а
«Содержание» — такая же глава, поэтому у неё своя страница.

В `style.css` есть и `break-before: page` для `h1` — это для печати
из браузера (Chrome/Firefox), Calibre эту строку игнорирует и пользуется
флагом `--page-breaks-before`.

## Ссылки на страницы (`{{page:N}}`)

«Смотри раздел 5, стр. 6» — номер заранее неизвестен: он зависит от
вёрстки, картинок и любой правки текста. Поэтому в markdown стоит метка
`{{page:5}}` («страница главы 5»), а `build.sh` собирает PDF в два прохода:

1. `pageref.py fill` подставляет номера из карты
   `instructions-<язык>.pages.json` (в первом проходе карты ещё нет —
   вместо номеров в текст попадёт `??`);
2. pandoc и Calibre собирают PDF, `pageref.py scan` читает его через
   `pdftotext` и выписывает, с какой страницы начинается каждая глава;
3. если карта изменилась, проход повторяется (обычно хватает двух), пока
   номера не совпадут. Всего до четырёх проходов, потом `build.sh`
   предупредит, что номера «плывут».

Глава ищется по началу страницы: перед каждой главой стоит разрыв, а на
странице «Содержание» заголовки идут не первыми. Метки можно ставить где
угодно — в содержании, словарике, тексте; номер подставится при сборке.
`instructions-*.pages.md` и `*.pages.json` — промежуточные файлы, в git
их нет (они в `.gitignore`).

## Мелочи, о которых стоит помнить

* Эмодзи в тексте не используем — в PDF они не рисуются. Для шагов
  программы есть свои символы (`↑ ↓ ← → ‖ ✦ ●`), для звёздочек
  сложности — `★`, для разделителей — `·`.
* Слово в слово одинаковые структуры инструкций (одни и те же главы,
  одинаковые страницы) упрощают жизнь: можно печатать обе версии и
  сверять картинку.
* Тексты рассчитаны на ребёнка, но раздел «Взрослым» в конце — для
  родителей: установка, флаги, калибровка.
